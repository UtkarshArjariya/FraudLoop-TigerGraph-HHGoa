# FRAUDLOOP — four-minute demo script

This script uses the preserved benchmark answers and **Replay**. It does not require live Gemini or TigerGraph calls for the timeline. Additional verification replies are simulations, and SAR/card actions are recommendations. Keep the recording at 1920×1080 if possible; do not show `.env`, terminal history containing credentials, or developer tools.

Start the demo with `make demo`. Open `http://localhost:5173/`. Before recording, wait for the queue and health indicators to settle. Use the dark theme, close browser sidebars, and select **viewer** in the top-bar role switcher. Have `http://localhost:5173/cases/HHG-002` ready in a second tab if needed. Start both replays only when the script calls for them; do not click **Run live**.

## Recording checks

- Confirm that **Replay** shows a replay label and that saved historical events are distinguished from newly measured live events. If a tool event lacks a historical measurement, do not describe its duration as measured.
- If health is degraded, leave the status visible and continue in replay. Do not claim that all services are healthy or that all embedding indexes are complete.
- If the graph tab uses a local prepared-data neighborhood, retain its fallback label. The graph exploration can remain useful without being a live query.
- The strongest changed-recommendation example is **HHG-002**, not HHG-010 or HHG-015: those uncertain cases retain their actions because the analyst simulation supplies no decisive evidence.
- Use **HHG-014** as the cross-customer ring example. HHG-006 is purchase splitting on one identified card with historical analogies, not proof of a current shared actor.
- Screenshots should be captured from the actual running interface. Suggested files: `docs/screenshots/queue.png`, `hhg-014-detail.png`, `graph.png`, and `approvals.png`.

If the UI uses a different displayed label from this script, update the click instruction to the final label before recording. The routes and case IDs are the stable navigation targets.
